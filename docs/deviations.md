# Architecture Deviations

| Item | Reason | Impact | Decision | Authority/writeback |
|---|---|---|---|---|
| SDK pin is `10.0.400` | This is the installed stable .NET 10 feature band used by Visual Studio and CI bootstrap | Replaces the older planning example `10.0.1xx`; exact pin prevents SDK-driven lock-file drift | Accept exact stable SDK only | Step 01 evidence |
| WebAssembly SDK pack is pinned to `10.0.11` | SDK `10.0.400` host distributions can otherwise advertise `10.0.10` or `10.0.11` for the implicit pack | Without the override, a lock file generated by Visual Studio fails locked restore on a clean CI runner | Override the `net10.0` known pack metadata centrally | PR #8 restore evidence |
| vcpkg uses the checkout documented by deployment guidance | Native packages are installed once in the developer or runner vcpkg tree | Removes three manifests, ten custom triplets, and repository-local dependency trees while retaining the reviewed package set | Record the checkout and install commands in `deploy/README.md`; review upgrades as one dependency change | vcpkg integration simplification |
| Repository policy uses tests and standard CI tools instead of helper scripts | Tracked PowerShell/shell helpers duplicated build logic and produced platform-specific policy behavior | Policy is enforced by ArchitectureTests, .NET analyzers, clang-tidy, Super-Linter, dependency review, and direct CLI commands | Keep `eng/build` declarative (`.props`/`.targets`) and place executable verification in tests/workflows | Security and quality gate PR |
| `ArcForges.Foundation` contains runtime primitives only | Stable serialized IDs belong to Contracts | Avoids duplicate nominal identities | `ArcForges.Contracts.Foundation` is the single serialized-ID owner | Step 02 confirms contracts |
| MAUI uses one conditional multi-target head | One app owns Android and deferred iOS platform folders | No duplicate platform heads | Keep `ArcChat.Mobile.csproj` as the only MAUI executable | Steps 18–20 |
| Stable MAUI 10.0.90 resolves `Xamarin.AndroidX.Security.SecurityCrypto/1.1.0.4-alpha07` | This exact AndroidX binding is a transitive dependency selected by the frozen stable MAUI package and has no stable 1.1.0.4 replacement on nuget.org | Android head alone carries one audited prerelease-labeled transitive; ArcForges never references it directly | Keep an exact one-entry policy allowlist; any other prerelease still fails CI | Step 01 dependency evidence; revisit with each MAUI upgrade |
| Step 00 docs-only evidence landed without a README/layout deviation | The six-repository baseline was recomputed and matched the frozen snapshot (zero drift); no product/architecture stance changed | Scope/source/license/manifest/traceability evidence only | No deviation; `ArcForges.Foundation` stable-ID single-location ruling (`ArcForges.Contracts.Foundation`) is recorded here per its own row and formally adjudicated in Step 02 | Step 00 evidence + ledger |
| Step 00 verification scripts are not tracked | The plan's `docs/tools/check-*.ps1` and `eng/traceability/generate-feature-trace-bridge.ps1` mandates conflict with `RepositoryPolicyTests.NativeDirectDependenciesAreRegisteredAndSupplyChainGatesStayEnabled`, which forbids any tracked `.ps1`/`.sh` (no carve-out) | `managed` CI failed listing all 8 scripts | Keep `eng/`/`docs/` free of tracked helper scripts; the Step 00 gate assertions were executed as one-time recorded verification (evidence in `docs/execution/step-00-ledger.md`) | Plan 00-scope-and-source-inventory `docs/tools/*.ps1` script requirement conflicts with repository policy; flagged for authority repair (rescue a test/CI-based gate) |
